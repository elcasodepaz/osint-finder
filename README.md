# 🕵️‍♂️ OSINT-Finder

**OSINT-Finder** is a beginner-friendly, terminal-based OSINT tool that helps you gather public information on **phone numbers**, **usernames**, and **IP addresses** using common search engine techniques and publicly available resources.

---

## ⚠️ Legal Disclaimer
> This tool is for **educational purposes only.** Use it **only** on data you own or have explicit permission to investigate. Do **not** use it for stalking, harassment, or illegal surveillance. Violating privacy laws may lead to prosecution.

---

## 💡 Features
- 🔍 Search phone numbers across public platforms
- 🧠 Lookup usernames on multiple services
- 🌐 Perform simple IP geolocation queries
- 📦 Lightweight & easy to run on Kali, Parrot, or Ubuntu

---

## 📦 Requirements
- Python 3.x
- `requests`
- `colorama`

Install requirements:
```bash
pip install -r requirements.txt
```

---

## 🚀 Usage
Run the tool with:
```bash
python3 osint-finder.py
```
Follow the interactive menu to:
- Enter a phone number
- Enter a username
- Enter an IP address
