# osint-finder 🔍

### 🥷 CyberFight Ops HQ Tool by CyberEyez (FireFightsTV)

`osint-finder.py` is a lightweight terminal tool that scans the web for a username across major platforms — perfect for cyber investigations, digital recon, or just checking your online footprint.

---

## ⚙️ What It Does

- Enter a username (e.g. `cybereyez`)
- Instantly scan major websites like:
  - GitHub
  - Twitter (X)
  - Instagram
  - Reddit
  - TikTok
  - YouTube
  - Dev.to
  - Medium
  - HackerRank
- Returns links where that name is found ✅

---

```bash
python3 osint-finder.py
